# Nachtwache

Ein browserbasiertes Low-Poly-Zombie-Survivalspiel mit einer kurzen Story in drei Akten.

## Steuerung

- **WASD / Pfeiltasten:** bewegen
- **Maus:** zielen, Linksklick schießt
- **Shift:** sprinten
- **E:** interagieren
- **R:** nachladen
- **F:** Taschenlampe
- **Escape:** Pause

## Assets

Die eingebundenen 3D-Modelle stammen aus Kenneys **Graveyard Kit** und **Survival Kit**. Beide Packs stehen unter Creative Commons CC0. Kopien der Lizenztexte liegen unter `public/models/kenney/`.
